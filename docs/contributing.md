# Contributing

Documentation about the codebase itself, for whoever works on it next,
rather than about using the app:

- [`style-guide.md`](style-guide.md) — UI conventions already established by
  the existing templates and stylesheet, so new pages match instead of
  drifting into inconsistent, unstyled markup.
- [`references.md`](references.md) — authoritative sources for species
  codes, names, and file formats. Check here before hand-entering a code or
  a chunk layout.
